# Opportunities

Start with the [service-product list](service-products.md), ordered roughly by demand in Iran. Each service lists its different models, including niche models with little current local demand.

To start a project:

1. Choose a service (Product Family).
2. Choose a specific model (Variant).
3. Record both in the [Selected Opportunity Brief](../templates/selected-opportunity-brief.md) and [project tracker](../templates/project-tracker.md).
4. Continue to [Phase 01](../phases/01-product-discovery.md).

For example: **Barbershop / Beauty Salon Booking → Women’s single-salon**. This means one physical women’s salon; marketplace, multi-branch, and at-home models are separate choices.

Use plain service and model names. Keep project status in the [project index](../projects/README.md) and trackers.
